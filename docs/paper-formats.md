# Paper formats and layout

| Name | Width × height (mm) |
| --- | ---: |
| A4 | 210 × 297 |
| US Letter | 215.9 × 279.4 |
| A5 | 148 × 210 |
| Legal | 215.9 × 355.6 |

Landscape swaps width and height. Layout defaults are 10 mm page margins, a 15 mm title band, an 8 mm weekday band, and a 20 mm notes band. Each can be changed with CLI options. Calendar rows and blank-grid columns divide the remaining content area evenly.

The returned layout describes mathematical page geometry. It does not promise a printer can print to the edge or account for device-specific printable areas.
