# Security policy

## Supported version

Security fixes are published against the latest supported release.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository. Do not include credentials, tokens, or personal information in a public issue. Reports will be reviewed and a fix or mitigation will be prepared before public disclosure when practical.

The renderer has no runtime dependencies and performs no outbound network requests for calendar generation. HTTP mode is read-only and accepts GET requests only.
