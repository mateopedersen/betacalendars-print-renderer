# Changelog

## 1.0.0 — 2026-10-07

- Initial deterministic print renderer release.
- Added month, year, inclusive range, and undated blank-grid rendering to SVG, PDF, and JSON.
- Added Gregorian topology and physical print-layout inspection.
- Added optional read-only HTTP endpoints and health check.
- Added multi-architecture Docker publishing workflow with SBOM and provenance.
